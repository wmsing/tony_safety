AI 代理现已在员工设备、云平台以及开发者工作流中运行。安全团队需要能够发现这些代理，管控其可访问范围，并在出现问题时对其进行遏制。本月的更新将帮助您发现和管控本地 AI 代理，将 [零信任](https://www.microsoft.com/en-us/security/business/zero-trust) 扩展至代理流量，并加强依赖 AI 时代运营的安全运营中心 (SOC) 基础架构。

以下是新增内容：

## 借助 Microsoft Defender 扩展保护范围并支持调查

![显示 Microsoft Defender 门户中本地 AI 代理清单的截图，列出了已发现的代理。](https://www.microsoft.com/en-us/security/blog/wp-content/uploads/2026/09/Picture1-2.webp)

### 借助 Microsoft Security Copilot 为邮件调查和狩猎提供更多上下文

对于同时使用 [Microsoft Defender](https://www.microsoft.com/en-us/security/business/microsoft-defender) 和 [Microsoft Security Copilot](https://www.microsoft.com/en-us/security/business/ai-machine-learning/microsoft-security-copilot) 的组织，[新的邮件引爆摘要](https://learn.microsoft.com/en-us/defender-office-365/security-copilot-in-email-entity#detonation-summary) 提供了 AI 生成的 URL 和文件沙箱结果解释。这有助于安全运营中心 (SOC) 团队加快调查速度，通过减少关联引爆证据和上下文信号所需的手动工作量来实现这一目标。

![显示 Microsoft 安全门户的截图，其中包含“邮件协作”>“资源管理器”下的“引爆测试”调查，展示了检测详情和时间线事件以审查可疑邮件活动。左侧导航栏列出检测属性，中间表格按时间戳和来源组织事件，右侧 Copilot 面板提供“邮件摘要”和“引爆摘要”卡片。](https://www.microsoft.com/en-us/security/blog/wp-content/uploads/2026/09/Picture2-1-1024x480.webp)

## 借助 Microsoft Purview 和 Microsoft Entra 保护传输中的敏感数据

### 阻止敏感数据通过网络流向影子 AI

现已普遍可用，[Microsoft Purview](https://www.microsoft.com/en-us/security/business/microsoft-purview) 和 Microsoft Entra 全局安全访问将数据安全扩展至网络，涵盖人类操作以及代理流量（OBO）。上下文感知的 Microsoft Purview 分类策略由 Entra 在网络层执行。组织可以实时发现敏感文件和文本，并阻止其共享到高风险目的地。例如，如果员工或 OBO 代理尝试将敏感文档上传到未授权的 AI 工具，策略可以在数据离开之前阻止传输。

![显示 ChatGPT Web 界面的截图，其中包含请求 400 字技术简报的对话，可见侧边栏导航和助手响应文本。红色错误横幅和粉色重试通知表明响应生成失败，而 Microsoft Copilot 通知出现在右下角。](https://www.microsoft.com/en-us/security/blog/wp-content/uploads/2026/09/Picture3-2.webp)

_防止员工将专有或敏感组织数据共享到潜在风险位置（如消费级 AI 应用程序）。_

## **借助 Microsoft Purview 保护、调查并清理企业数据**

### 以较少的管理开销实现企业规模的标签管理

[Microsoft Purview 自动标记](https://learn.microsoft.com/en-us/purview/deploymentmodels/depmod-secure-by-default-step1) 可帮助组织在企业规模上自动将数据安全控制应用于敏感内容。新的自动标记增强功能改进了策略规模、管理员体验和报告。策略现在支持通过自适应范围模拟多达 2000 万项内容和 50,000 个站点。管理员可以编辑策略而无需重新运行模拟。新的审计洞察和报告显示了策略覆盖率和处理活动。这些增强功能共同帮助组织以更少的管理努力在企业级环境中扩展自动标记。

### 通过既定的合规流程调查在 Copilot 应用程序（如 Microsoft Loop、Copilot 页面）中创建的内容

Microsoft Purview eDiscovery 现在支持 [搜索、保留、审查和导出](https://learn.microsoft.com/en-us/purview/edisc-data-sources) 用户拥有的 SharePoint 嵌入式容器中的内容，以帮助简化法律、监管和内部调查的 eDiscovery 流程。调查人员可以找到来自 AI 驱动体验的内容，包括 Microsoft Loop、Copilot Pages、Copilot Notebooks 以及应用程序（如 Outlook 通讯），这些内容已映射到用户，而无需向 SharePoint 管理员请求容器 URL。可选的 HTML 转换可生成下游法律工具更易读的版本，从而改善专家的审查和导出体验。

### 归档并永久删除不活跃内容以提升 AI 就绪状态

借助 Microsoft Purview 数据生命周期管理，管理员现在可以 [归档不活跃的 SharePoint 内容](https://learn.microsoft.com/en-us/purview/retention-settings#archiving-retained-sharepoint-files)，而无需归档整个站点。已归档的内容仍受保留和法律诉讼保留策略的约束，并且对 eDiscovery 仍可发现，但会退出 Microsoft 365 Copilot 索引（直到重新激活）。组织还可以使用 [优先清理](https://learn.microsoft.com/en-us/purview/priority-cleanup-permanent-deletion) 永久删除已批准的内容（包括过时的 Teams 录音和转录），使其不再在 eDiscovery、SharePoint 搜索或 Microsoft 365 Copilot 中可发现。这些功能共同帮助组织满足合规法规，包括高度监管行业的法规。

## **借助 Microsoft Intune 将高级端点管理扩展至 GCC High 和 DoD**

### 将现代化的端点管理引入受监管环境

[Microsoft Intune 企业应用管理](https://www.microsoft.com/en-us/security/business/endpoint-management/microsoft-intune-enterprise-application-management)、[Microsoft Cloud PKI](https://www.microsoft.com/en-us/security/business/endpoint-management/microsoft-cloud-pki) 和 [Intune 远程协助](https://www.microsoft.com/en-us/security/business/endpoint-management/microsoft-intune-remote-help) 即将推出至 [高安全需求政府社区云 (GCC High)](https://techcommunity.microsoft.com/blog/publicsectorblog/advanced-microsoft-intune-capabilities-are-now-available-for-gcc-high/4555814)。同时，企业应用管理功能也将提供给美国国防部（DoD）相关组织。这些能力可帮助政府和国防组织简化应用管理、现代化证书生命周期管理、更快解决设备问题并降低总体拥有成本，同时确保在经认证的云环境中运行。
